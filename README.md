# Voltez5_electic_Project

C++ Console-Based Household Electricity Usage Calculator and Energy Saving Recommendation System

Project Overview:
The Household Electricity Usage Calculator and Energy Saving Recommendation System is a program designed to help households monitor and manage their electricity consumption. The system allows users to input appliance information such as appliance name, wattage, and hours of usage, then calculates the total electricity consumption in kilowatt-hours (kWh) and estimated electricity cost. Based on the user’s desired savings goal, the program also provides practical recommendations to reduce energy usage and save money. This project supports SDG 7 – Affordable and Clean Energy by encouraging efficient and responsible energy consumption.

Key Features:
The system allows users to input appliance details including appliance name, wattage, and hours of usage. It calculates electricity consumption in kilowatt-hours (kWh) and estimates the total electricity cost based on usage. The program also provides energy-saving recommendations to help users reduce electricity expenses and reach their savings goals. In addition, the system includes input validation to prevent invalid entries and displays all recorded appliance data for easier monitoring and review. The project uses a menu-driven interface that enables users to easily navigate different functions such as data input, computation, report generation, and program exit.
